# Engines

<!-- Generated from the Everso repository by `npm run designs:kit` — don't edit here. -->

An engine is the code that draws an invitation: its opening, layout, date
reveal and motion. A design dresses one engine. Pick the engine that fits
the occasion, start from one of its examples, and use its artwork guide to
make matching art. The **settings** each engine takes are in the
[settings reference](spec.md).
