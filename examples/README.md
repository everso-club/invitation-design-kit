# Examples

| Example | Shows |
|---|---|
| [`kalyana-classic`](kalyana-classic/) | The original Kalyana look: every setting at its default. A design can be this small. |
| [`kalyana-peacock`](kalyana-peacock/) | A full re-dress: new colours, fonts and wording, a recoloured door panel and petals. |

Preview one with `npm run preview -- kalyana-peacock`, or copy one to start
your own with `npm run new -- <id> --from kalyana-peacock`.

Please don't edit the examples themselves. Copy them instead.
