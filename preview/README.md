# Preview app

Generated by Everso. Don't edit.

- `app/`: the design preview page and the invitation renderer, prebuilt. It
  is the same code guests see in the Everso app, minus sign-in and RSVP,
  which are faked with sample data.
- `invite-templates/`: each engine's default artwork, used for every slot
  your design doesn't replace.

`npm run preview` serves these with your design folder. The engines'
default music isn't included: its licence doesn't allow sharing the file.
